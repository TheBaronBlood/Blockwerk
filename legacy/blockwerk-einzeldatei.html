So kommt das Programm auf den Hub
  1. Einmalig: In Pybricks Code über das Zahnrad die Pybricks-Firmware auf den Hub spielen.
  2. Hier auf »Kopieren« klicken.
  3. In Pybricks Code eine neue Python-Datei anlegen und den Code einfügen.
  4. Hub per Bluetooth verbinden und das Programm starten.
