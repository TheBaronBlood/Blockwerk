      So kommt das Programm auf den Hub
      
    
        
  1. Einmalig: In Pybricks Code über das Zahnrad die Pybricks-Firmware auf den Hub spielen.
    2. 
        
  2. Hub einschalten und unten rechts auf den grünen Startknopf klicken. Bluetooth oder USB-Kabel wählen, dann den Hub auswählen.
    3. 
        
  3. Das Programm wird übertragen und läuft sofort los. Der rote Knopf oder die mittlere Taste am Hub beendet es.
    4. 
      

      
Über das USB-Kabel geht es nur mit einer Pybricks-Firmware, die USB kann (derzeit die Beta 4.1). Mit der normalen Firmware bitte Bluetooth nehmen.

      
Dieser Browser kann sich nicht mit dem Hub verbinden. Nimm Chrome oder Edge – oder kopiere den Code und füge ihn in Pybricks Code in eine neue Python-Datei ein.
